1
ZIP Dosyasını İndirin ve Açın

İndirdiğiniz ysy_sigorta_website.zip dosyasını bilgisayarınızda bir klasöre çıkarın.

Çıkardığınızda şu yapıyı göreceksiniz:

ysy_sigorta/
├── index.php          ← Ana sayfa
├── kurumsal.php
├── urunlerimiz.php
├── subelerimiz.php
├── blog.php
├── iletisim.php
├── submit_form.php
├── .htaccess
├── admin/             ← Admin paneli
├── data/              ← JSON veritabanı (koruyun!)
├── includes/          ← Ortak header/footer
└── uploads/           ← Görseller & logo
2
Dosyaları Hostinge Yükleyin (FTP)

Yöntem A – cPanel File Manager (En kolay)

  1. Hosting panelinize giriş yapın (genellikle siteadiniz.com/cpanel)
  2. File Manager → public_html klasörünü açın
  3. Sağ üstten Upload butonuna tıklayın
  4. ysy_sigorta_website.zip dosyasını yükleyin
  5. Yüklenen ZIP üzerine sağ tıklayın → Extract seçin
  6. Çıkan ysy_sigorta klasörünün içindeki tüm dosyaları public_html/'e taşıyın
⚠️

Dikkat: public_html/ içine ysy_sigorta klasörü değil, klasörün içindeki dosyalar gelmeli. Yani public_html/index.php olmalı, public_html/ysy_sigorta/index.php değil.

Yöntem B – FileZilla (FTP programı)

  1. FileZilla'yı indirin ve kurun
  2. Hosting firmanızdan aldığınız FTP bilgilerini girin:
    Host: ftp.siteadiniz.com  |  Kullanıcı adı & Şifre
  3. Sol panel (bilgisayarınız): ysy_sigorta/ klasörünü bulun
  4. Sağ panel (sunucu): public_html/ klasörüne gelin
  5. Sol panelden tüm dosyaları seçip sağ panele sürükleyin
3
Klasör İzinlerini Ayarlayın

Site çalışması için bazı klasörlerin yazılabilir olması gerekir.

cPanel File Manager ile:

  1. File Manager'da public_html/data/ klasörüne sağ tıklayın
  2. Change Permissions seçin → 755 yazın → OK
  3. Aynı işlemi şu klasörler için tekrarlayın:
KlasörİzinNeden?
data/755JSON kayıtlarını yazabilmek için
uploads/755Görsel yükleyebilmek için
uploads/genel/755Logo yükleyebilmek için
uploads/blog/755Blog görseli yükleyebilmek için

SSH / Terminal ile (alternatif):

chmod 755 data/ uploads/ uploads/genel/ uploads/blog/
chmod 644 data/*.json

ℹ️ İzin vermede sorun yaşarsanız hosting destek ekibinizden yardım isteyin. "data ve uploads klasörlerine 755 yazma izni gerekiyor" deyin.

4
Admin Paneline Giriş Yapın

Tarayıcınızda şu adrese gidin:

https://siteadiniz.com/admin
AlanDeğer
URL/admin veya /admin/index.php
Varsayılan Şifrepassword
🔐

Güvenlik: Giriş yaptıktan hemen sonra Admin Panel → Şifre Değiştir menüsünden şifrenizi mutlaka değiştirin!

5
Logo ve Site Ayarlarını Yapın
  1. Admin paneline giriş yapın
  2. Sol menüden Fotoğraflar & Logo'ya tıklayın
  3. Logo sekmesinde "Tıklayın veya sürükleyin" alanına logonuzu yükleyin
  4. Sol menüden Site Ayarları'na gidin
  5. Telefon, e-posta, adres, WhatsApp numarasını güncelleyin
  6. Değişiklikleri Kaydet'e tıklayın

✅ Logo ve iletişim bilgilerini güncellediğinizde site otomatik olarak güncellenir, yeniden yükleme gerekmez.

🔧 Sık Karşılaşılan Sorunlar

Sayfa açılmıyor / 500 hatası

  • .htaccess dosyası yüklendi mi kontrol edin (gizli dosya olabilir – FileZilla'da Sunucu → Gizli Dosyaları Göster)
  • Hosting panelinizde mod_rewrite aktif mi kontrol edin
  • PHP sürümünüzün 7.4+ olduğundan emin olun

Logo görünmüyor

  • uploads/genel/ klasörüne yazma izni (755) verildi mi?
  • Admin → Fotoğraflar & Logo'dan logoyu tekrar yükleyin

Form gönderilmiyor

  • data/ klasörüne yazma izni (755) verildi mi?
  • data/forms.json dosyası var mı? (ZIP ile gelmelidir)

Admin sayfasına giremiyorum

  • Doğru adres: siteadiniz.com/admin ya da siteadiniz.com/admin/index.php
  • Varsayılan şifre: password

Ürünler/Blog görünmüyor

  • Admin panelinden ürünlerin "Aktif" olarak işaretlendiğinden emin olun
  • data/products.json dosyasının sunucuda var olduğunu kontrol edin

ℹ️ Herhangi bir sorun için sitenin PHP hata loglarına bakın. cPanel → Errors veya Raw Access Logs bölümünden erişebilirsiniz.
